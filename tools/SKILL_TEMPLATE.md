# Authoring guide for the per-app skills (not shipped as a skill)

Each Crafting App skill lives in `skills/<app>/` and has:

- `SKILL.md` (under ~250 lines)
- `references/commands.md` — GENERATED by `tools/gen-catalog.sh`; never edit by hand
- `references/recipes.md` — task recipes, every one actually run against the CLI

## SKILL.md shape

```markdown
---
name: <app>
description: <What the app is (Adobe/other equivalent) + what the skill does + a pushy list of trigger
  contexts: file types, verbs, tasks, "even if the user doesn't name <App>". One paragraph, < 1024 chars.>
---

# <App> (`<app>-cli`)

One-paragraph orientation: what the app is, the native file format, what it reads/writes.

## Before you start
- Check `command -v <app>-cli`. If missing, use the `artcraft` skill's installer
  (`skills/artcraft/scripts/craft-clis.sh install <app>`; Windows: `craft-clis.ps1`).
- Headless by default. The running app is only needed for `--bridge/--connect` (explain the flag for THIS cli).

## When to use / when not
Short bullets; name the sibling Craft app for adjacent jobs.

## Core workflows
The 4–8 most common jobs as copy-pasteable, TESTED commands, each with one line of why.

## Finding the right command
How to search this CLI's registry (`commands --filter`, `describe`, `tools`, …) and how to read the
param spec. Point to references/commands.md for offline grep.

## Safe defaults
Write to new files; never overwrite inputs unless asked; confine MCP with automation roots; quote paths.
Only the parts that apply to this CLI.

## Gotchas
Real ones you hit while testing (units, ticks, page numbering, exit codes, fonts, etc.).

## References
- references/recipes.md — when to read it
- references/commands.md — when to grep it
```

## Rules
- English. Imperative voice. Explain *why* rather than shouting MUST.
- Only document commands and flags you ran successfully (or that the CLI's own help shows verbatim).
- Portable: no user-specific paths, no references to tools outside this plugin (except the sibling
  `artcraft:*` skills). Use `$HOME`/relative paths in examples.
- Generative AI (making new images/video/audio from prompts) is the `genai` skill's job; mention it
  as the hand-off when relevant, never call a generator directly.
